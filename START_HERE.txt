START HERE

This is my Lab 12 Basic Express Server project.

1. Open the project folder in VS Code.

2. Open the terminal in VS Code.

3. Install the dependencies:

npm install

4. Start the server:

npm start

5. Look for this message:

Server is running on port 3000

6. Open the home page:

http://localhost:3000/

7. Open the contact page:

http://localhost:3000/contact

8. When you are finished, return to the terminal and press:

Control + C
